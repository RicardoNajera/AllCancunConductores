# All Cancún Conductores

PWA para conductores: reciben solicitudes, aceptan viajes y comparten su ubicación.
Misma base de datos Supabase que All Cancún (cliente) y All Cancún Comercios.

## Uso local

```bash
node dev-server.mjs   # http://127.0.0.1:8767
```

## Publicar

```bash
./publicar.sh
```
